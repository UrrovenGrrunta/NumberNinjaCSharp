# NumberNinja C#

C# rewrite of **NumberNinja**, a small maths training game originally written in Python with Kivy.

The goal of this version is to rebuild the project with a cleaner C# architecture while keeping the original gameplay and features.

## Planned stack

- **C# / .NET**
- **Avalonia UI** for the desktop GUI
- **System.Text.Json** for local JSON data

## Planned features

- Multiple difficulty levels
- Randomly generated maths questions
- Four answer options per question
- Points system
- Streak system
- Score multiplier
- Challenge mode with a countdown timer
- Time penalty for incorrect answers in Challenge mode
- Random maths facts
- Sound effects

## Development status

Early development / rewrite stage.

The first goal is to port the core game logic and question generators before rebuilding the GUI.
